# Matrix Machines

An intuition-first linear algebra game: a 2×2 matrix is a machine that moves the plane.
Drag points, build shapes, describe matrices in plain words, and run the machine backwards
to see when systems of equations have one, none, or infinitely many solutions.

All examples use small whole numbers so you can do the arithmetic in your head.

Play: https://alex-lewandowski.github.io/intuitive_linear_algebra/
